# Wonderlands art assets

All new illustrations below were generated for Wonderlands in this task. No third-party stock asset pack or runtime generation service is used.

- `terrain-atlas.png`: a transparent 3 × 2 atlas of six independent illustrated relief assets: hill, mountain, grove, village, port, fortress. The renderer selects each cell of this atlas and composes it over the editable terrain. This is not a map image.
- `ground-textures.png`: two ground materials, lush jade meadow and amber savanna. They contain no coast, river, settlement, map outline, or prearranged game layout. They are clipped to the player-created land geometry.
- `ocean.png`: surrounding atmospheric ocean and cloud illustration, outside the editable board only.
- `icon.svg`: small original vector planet icon. BEEP is an original vector character embedded in the main HTML.
- `island.png`: historical Stage A fixed-map art study. It is retained only for provenance and the archived proof, never loaded by the playable game, and excluded from the release package.

The supplied concept and layout sketch are preserved unmodified in `docs/handoff/` for reference. They are never loaded by the playable game and are excluded from the release.
